**Visão Geral**

O site GRÃO & AROMA é uma cafeteria artesanal que busca apresentar sua oferta de produtos e serviços de alta qualidade. A arquitetura do site é moderna, responsiva e fácil de usar, com uma identidade visual que combina marrom e caramelo como cores predominantes.

**Módulos**

1. **Início**: Página inicial com uma seção principal que apresenta a cafeteria e seus produtos.
2. **Cardápio**: Seção que lista os produtos e serviços da cafeteria.
3. **Unidades**: Seção que apresenta as unidades da cafeteria.
4. **Pedidos**: Seção que lista os pedidos atuais.
5. **Rodapé**: Seção que apresenta o nome da cafeteria e informações de contato.

**Arquivos**

1. **index.html**: Página inicial com a seção principal.
2. **style.css**: Arquivo CSS que define as estilos do site.
3. **script.js**: Arquivo JavaScript que define as funcionalidades do site.

**Tabelas do Banco de Dados**

1. **produtos**: Tabela que armazena os produtos da cafeteria.
	* `id` (int, primário)
	* `nome` (varchar(50), nome do produto)
	* `descricao` (varchar(200), descrição do produto)
	* `categoria` (varchar(20), categoria do produto)
	* `preco` (decimal(10, 2), preço do produto)
	* `imagem` (varchar(200), imagem do produto)
2. **unidades**: Tabela que armazena as unidades da cafeteria.
	* `id` (int, primário)
	* `nome` (varchar(50), nome da unidade)
	* `endereço` (varchar(100), endereço da unidade)
	* `bairro` (varchar(50), bairro da unidade)
	* `horario` (varchar(20), horário de funcionamento da unidade)
3. **pedidos**: Tabela que armazena os pedidos atuais.
	* `id` (int, primário)
	* `produto_id` (int, forãe do produto)
	* `quantidade` (int, quantidade do produto)
	* `status` (varchar(10), status do pedido)

**Rotas da API**

1. **GET /produtos**: Retornar os produtos da cafeteria.
2. **GET /unidades**: Retornar as unidades da cafeteria.
3. **GET /pedidos**: Retornar os pedidos atuais.
4. **POST /pedidos**: Adicionar um novo pedido.

**JavaScript**

```javascript
// Função para adicionar produto ao pedido
function adicionarProduto(pedidoId, produtoId) {
  fetch(`/${pedidoId}/produtos/${produtoId}`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      quantidade: 1
    })
  })
    .then(response => response.json())
    .then(data => console.log(data))
    .catch(error => console.error(error));
}

// Função para realizar pedido
function realizarPedido(pedidoId) {
  fetch(`/${pedidoId}/realizar`, {
    method: 'POST'
  })
    .then(response => response.json())
    .then(data => console.log(data))
    .catch(error => console.error(error));
}
```
