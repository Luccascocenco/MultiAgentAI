**Catálogo Completo de Livros Físicos e eBooks para Loja Online**

**1. Estrutura do Catálogo**

O catálogo será estruturado em seguintes pastas:

*   **livros-fisicos**
*   **ebooks**
*   **produtos-promocionados**
*   **avaliacoes**
*   **pedidos**

**2. Estrutura dos Arquivos e Pastas**

*   **livros-fisicos**
    *   **livros-fisicos.csv** ( arquivo de CSV para armazenar os dados dos livros físicos)
    *   **livros-fisicos.json** ( arquivo JSON para armazenar os dados dos livros físicos em formato JSON)
*   **ebooks**
    *   **ebooks.csv** ( arquivo de CSV para armazenar os dados dos eBooks)
    *   **ebooks.json** ( arquivo JSON para armazenar os dados dos eBooks em formato JSON)
*   **produtos-promocionados**
    *   **produtos-promocionados.csv** ( arquivo de CSV para armazenar os dados dos produtos promocionados)
    *   **produtos-promocionados.json** ( arquivo JSON para armazenar os dados dos produtos promocionados em formato JSON)
*   **avaliacoes**
    *   **avaliacoes.csv** ( arquivo de CSV para armazenar as avaliações dos clientes)
    *   **avaliacoes.json** ( arquivo JSON para armazenar as avaliações dos clientes em formato JSON)
*   **pedidos**
    *   **pedidos.csv** ( arquivo de CSV para armazenar os pedidos dos clientes)
    *   **pedidos.json** ( arquivo JSON para armazenar os pedidos dos clientes em formato JSON)

**4. Busca por Título, Autor ou Palavra-Chave**

*   Utilizar o motor de busca Elasticsearch para indexar os dados dos produtos
*   Utilizar a API do Elasticsearch para realizar a busca

**5. Filtros por Categoria, Autor, Tipo de Produto e Faixa de Preço**

*   Utilizar o motor de busca Elasticsearch para indexar os dados dos produtos
*   Utilizar a API do Elasticsearch para realizar os filtros

**6. Ordenação por Preço, Avaliação, Mais Vendidos e Lançamentos**

*   Utilizar o motor de busca Elasticsearch para indexar os dados dos produtos
*   Utilizar a API do Elasticsearch para realizar a ordenação

**7. Controle de Estoque para Livros Físicos**

*   Utilizar um sistema de gerenciamento de estoque para armazenar a quantidade de livros físicos em estoque
*   Utilizar a API do sistema de gerenciamento de estoque para atualizar a quantidade de livros físicos em estoque

**8. Controle de Disponibilidade para eBooks**

*   Utilizar um sistema de gerenciamento de estoque para armazenar a disponibilidade de eBooks
*   Utilizar a API do sistema de gerenciamento de estoque para atualizar a disponibilidade de eBooks

**9. Cadastro de Promoções e Descontos**

*   Utilizar um sistema de gerenciamento de promoções para armazenar as promoções e descontos
*   Utilizar a API do sistema de gerenciamento de promoções para realizar a cadastro de promoções e descontos

**10. Avaliações e Comentários dos Clientes**

*   Utilizar um sistema de gerenciamento de avaliações para armazenar as avaliações e comentários dos clientes
*   Utilizar a API do sistema de gerenciamento de avaliações para atualizar as avaliações e comentários dos clientes

**11. Carrinho de Compras**

*   Utilizar um sistema de gerenciamento de carrinho para armazenar os itens que o cliente deseja comprar
*   Utilizar a API do sistema de gerenciamento de carrinho para atualizar o carrinho de compras

**12. Cálculo do Subtotal, Desconto e Valor Total**

*   Utilizar um sistema de gerenciamento de pedido para calcular o subtotal, desconto e valor total do pedido
*   Utilizar a API do sistema de gerenciamento de pedido para realizar o cálculo

**13. Diferenciação Clara entre Produtos Físicos e Digitais**

*   Utilizar uma página de landing para diferenciar os produtos físicos e digitais
*   Utilizar a API para atualizar a página de landing

**14. Cadastro de Capa/Imagem do Produto**

*   Utilizar um sistema de gerenciamento de capa para armazenar as capas e imagens dos produtos
*   Utilizar a API do sistema de gerenciamento de capa para atualizar as capas e imagens dos produtos

**15. Registro da Data de Cadastro e Última Atualização**

*   Utilizar um sistema de gerenciamento de registro para armazenar a data de cadastro e última atualização
*   Utilizar a API do sistema de gerenciamento de registro para atualizar a data de cadastro e última atualização
