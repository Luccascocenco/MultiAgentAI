**Banco de Dados**

Aqui está o banco de dados completo:

```sql
CREATE TABLE Contas (
  id INT AUTO_INCREMENT PRIMARY KEY,
  nome VARCHAR(255) NOT NULL,
  email VARCHAR(255) UNIQUE NOT NULL,
  senha VARCHAR(255) NOT NULL,
  cpf VARCHAR(11) UNIQUE NOT NULL,
  data_nascimento DATE NOT NULL,
  endereço VARCHAR(255),
  telefone VARCHAR(20),
  cidade VARCHAR(100)
);

CREATE TABLE Hamburguerias (
  id INT AUTO_INCREMENT PRIMARY KEY,
  nome VARCHAR(255) NOT NULL,
  descricao TEXT NOT NULL,
  preco DECIMAL(5,2) NOT NULL
);

CREATE TABLE Toppings (
  id INT AUTO_INCREMENT PRIMARY KEY,
  nome VARCHAR(255) NOT NULL,
  preco DECIMAL(5,2) NOT NULL,
  description TEXT NOT NULL
);

CREATE TABLE Sabores (
  id INT AUTO_INCREMENT PRIMARY KEY,
  nome VARCHAR(255) NOT NULL,
  descricao TEXT NOT NULL
);

CREATE TABLE Pedidos (
  id INT AUTO_INCREMENT PRIMARY KEY,
  cliente_id INT,
  data DATE NOT NULL,
  hora TIME NOT NULL,
  status ENUM('em_andamento', 'pagado', 'entregue') NOT NULL DEFAULT 'em_andamento',
  FOREIGN KEY (cliente_id) REFERENCES Contas(id)
);

CREATE TABLE Pedidos_Hamburguerias (
  id INT AUTO_INCREMENT PRIMARY KEY,
  pedido_id INT,
  hamburguria_id INT,
  topping_id INT,
  sabor_id INT,
  FOREIGN KEY (pedido_id) REFERENCES Pedidos(id),
  FOREIGN KEY (hamburguria_id) REFERENCES Hamburguerias(id),
  FOREIGN KEY (topping_id) REFERENCES Toppings(id),
  FOREIGN KEY (sabor_id) REFERENCES Sabores(id)
);

CREATE TABLE Historico (
  id INT AUTO_INCREMENT PRIMARY KEY,
  usuario_id INT,
  pedido_id INT,
  data DATE NOT NULL,
  hora TIME NOT NULL,
  FOREIGN KEY (usuario_id) REFERENCES Contas(id),
  FOREIGN KEY (pedido_id) REFERENCES Pedidos(id)
);
```

**Esquema das Tabelas**

*   **Contas**: armazena as informações dos usuários, incluindo o nome, e-mail, senha, CPF, data de nascimento e endereço.
*   **Hamburguerias**: armazena as informações das hamburguerias, incluindo o nome, descrição e preço.
*   **Toppings**: armazena as informações dos toppings, incluindo o nome, preço e descrição.
*   **Sabores**: armazena as informações dos sabores, incluindo o nome e descrição.
*   **Pedidos**: armazena as informações dos pedidos, incluindo o ID do pedido, data e hora do pedido, e o status do pedido.
*   **Pedidos_Hamburguerias**: armazena as informações das hamburguerias pedidas no pedido, incluindo o ID do pedido, a ID da hamburguria, o ID do topping e o ID do sabor.
*   **Historico**: armazena as informações do histórico de pedidos feitos pelo usuário, incluindo o ID do usuário, o ID do pedido e data e hora do pedido.

Espero que isso ajude a criar um esquema sólido para o banco de dados!
