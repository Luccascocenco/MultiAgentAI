Como um Engenheiro Back-End, vou focar em criar a estrutura básica do back-end do sistema de hamburgueria.

**Passo 1: Setup do Projeto**

Crie um novo projeto Node.js utilizando o comando `npm init`. Instale as dependências necessárias, incluindo o Express.js e a conexão com o banco de dados MySQL.
```bash
npm init -y
npm install express mysql2
```
**Passo 2: Definição da Estrutura do Banco de Dados**

Crie um arquivo `db.js` para definir a conexão com o banco de dados MySQL.
```javascript
const mysql = require('mysql2');

const db = mysql.createConnection({
  host: 'localhost',
  user: 'usuario',
  password: 'senha',
  database: 'hamburgueria'
});

db.connect((err) => {
  if (err) {
    console.error('Erro ao conectar ao banco de dados:', err);
  } else {
    console.log('Conectado ao banco de dados com sucesso!');
  }
});

module.exports = db;
```
**Passo 3: Definição das Tabelas do Banco de Dados**

Crie um arquivo `schema.sql` para definir as tabelas do banco de dados.
```sql
CREATE TABLE Contas (
  id INT AUTO_INCREMENT PRIMARY KEY,
  nome VARCHAR(255),
  email VARCHAR(255),
  senha VARCHAR(255)
);

CREATE TABLE Pedidos (
  id INT AUTO_INCREMENT PRIMARY KEY,
  cliente_id INT,
  data DATE,
  hora TIME,
  status ENUM('em_andamento', 'pagado', 'entregue'),
  FOREIGN KEY (cliente_id) REFERENCES Contas(id)
);

CREATE TABLE Historico (
  id INT AUTO_INCREMENT PRIMARY KEY,
  usuario_id INT,
  pedido_id INT,
  data DATE,
  hora TIME,
  FOREIGN KEY (usuario_id) REFERENCES Contas(id),
  FOREIGN KEY (pedido_id) REFERENCES Pedidos(id)
);
```
**Passo 4: Definição das Rotações do Back-end**

Crie um arquivo `routes.js` para definir as rotas do back-end.
```javascript
const express = require('express');
const router = express.Router();
const db = require('./db');

router.post('/login', async (req, res) => {
  const { email, senha } = req.body;
  const usuario = await db.query(`SELECT * FROM Contas WHERE email = ? AND senha = ?", [email, senha]);
  if (usuario.length > 0) {
    res.send({ message: 'Login sucesso!' });
  } else {
    res.send({ message: 'Login falhou' });
  }
});

router.post('/cadastrar', async (req, res) => {
  const { nome, email, senha } = req.body;
  const usuario = await db.query(`INSERT INTO Contas (nome, email, senha) VALUES (?, ?, ?)`, [nome, email, senha]);
  res.send({ message: 'Conta criada com sucesso!' });
});

router.post('/pedidos', async (req, res) => {
  const { cliente_id, data, hora, status } = req.body;
  const pedido = await db.query(`INSERT INTO Pedidos (cliente_id, data, hora, status) VALUES (?, ?, ?, ?)`, [cliente_id, data, hora, status]);
  res.send({ message: 'Pedido criado com sucesso!' });
});

router.get('/historico', async (req, res) => {
  const usuario = await db.query(`SELECT * FROM Contas WHERE id = ?`, [req.user.id]);
  if (usuario.length > 0) {
    const historico = await db.query(`SELECT * FROM Historico WHERE usuario_id = ?`, [usuario[0].id]);
    res.send(historico);
  } else {
    res.send({ message: 'Historico não encontrado' });
  }
});

module.exports = router;
```
**Passo 5: Definição da Rotina Principal**

Crie um arquivo `app.js` para definir a rotina principal do back-end.
```javascript
const express = require('express');
const app = express();
const router = require('./routes');

app.use(express.json());
app.use('/api', router);

app.listen(3000, () => {
  console.log('Back-end iniciado em http://localhost:3000/api');
});
```
Essa é a estrutura básica do back-end do sistema de hamburgueria. Você pode agora desenvolver as funcionalidades adicionais necessárias para o sistema.
