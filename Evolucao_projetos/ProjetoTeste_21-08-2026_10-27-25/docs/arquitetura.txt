**Catálogo de Arquitetura do Sistema**

**1. Entidade Principal**

* **Nome**: Loja Online de Livros
* **Descrição**: Plataforma de comércio eletrônico especializada na venda de livros físicos e eBooks.

**2. Funcionalidades**

* **Autenticação e Autoraização**
	+ Usuário
	+ Vendedor
	+ Cliente
* **Gerenciamento de Produtos**
	+ Adicionar novo livro físico ou eBook
	+ Atualizar detalhes de produto
	+ Excluir produto
* **Gerenciamento de Pedidos**
	+ Criar pedido
	+ Atualizar status de pedido
	+ Cancelar pedido
* **Gerenciamento de Contas**
	+ Criar conta de vendedor ou cliente
	+ Gerenciar histórico de compras
	+ Gerenciar balanço financeiro
* **Gerenciamento de Recursos**
	+ Gerenciar estoque físico
	+ Gerenciar biblioteca de eBooks

**3. Telas**

* **Pagina de Início**
	+ Objetivo: Apresentar os produtos principais e destacar ofertas atuais
* **Pagina de Produtos**
	+ Objetivo: Exibir lista de produtos, com detalhes e imagens
* **Pagina de Detalhes de Produto**
	+ Objetivo: Exibir detalhes específicos de um produto
* **Pagina de Pedidos**
	+ Objetivo: Exibir lista de pedidos em andamento e histórico de pedidos
* **Pagina de Contas**
	+ Objetivo: Exibir detalhes da conta do vendedor ou cliente
* **Pagina de Autenticação**
	+ Objetivo: Redirecionar usuário para página de autenticação
* **Pagina de Login**
	+ Objetivo: Exibir formulário de login e autenticação

**4. Tecnologias**

* **Plataforma de Aplicação**: Node.js com Express.js
* **Banco de Dados**: MongoDB
* **Armazenamento de Arquivos**: AWS S3
* **Certificado SSL**: SSL/TLS para proteger transações online
* **API de Pagamento**: Stripe para processamento de transações online

**5. Estrutura de Pastas**

* **Fontes**: /src/components/

**7. Requisitos de Desenvolvimento**

* **Habilidades necessárias**:
	+ Conhecimento de Node.js e Express.js
	+ Conhecimento de MongoDB e armazenamento de arquivos
	+ Conhecimento de certificado SSL e API de pagamento
	+ Conhecimento de construção de aplicação web
* ** Ferramentas necessárias**:
	+ Editor de código (por exemplo, Visual Studio Code)
	+ IDE (por exemplo, IntelliJ IDEA)
	+ Ferramenta de gerenciamento de versão (por exemplo, Git)

**8. Plano de Desenvolvimento**

* **Fase 1: Definição de Requisitos** (1 semana)
	+ Realizar entrevista com os stakeholders para entender as necessidades do sistema
	+ Criar mapa de requisitos e priorizar as funcionalidades
* **Fase 2: Design de Arquitetura** (1 semana)
	+ Criar catálogo de arquitetura do sistema
	+ Definir estrutura de pastas e arquivos necessários
* **Fase 3: Implementação de Arquitetura** (4 semanas)
	+ Implementar a arquitetura do sistema
	+ Desenvolver os serviços de negócios e construtores de aplicação
* **Fase 4: Testes e Depuração** (2 semanas)
	+ Realizar testes unitários e integrados
	+ Depurar erros e melhorar a performance do sistema
