**Visão Geral**

A loja de remédios online é um sistema de comércio eletrônico que permite aos usuários comprar remédios online. O sistema é composto por 3 módulos principais: 

- **Módulo de Registro**: onde os usuários podem se registrar para fazer compras.
- **Módulo de Compras**: onde os usuários podem visualizar e comprar remédios.
- **Módulo de Administração**: onde o administrador pode gerenciar os produtos, fornecedores e informações do sistema.

**Módulos**

1. **Módulo de Registro**
2. **Módulo de Compras**
3. **Módulo de Administração**

**Lista de Arquivos**

1. **static/index.html** - arquivo de entrada do sistema
2. **static/style.css** - arquivo de estilos do sistema
3. **static/script.js** - arquivo de scripts do sistema
4. **backend.py** - arquivo de backend do sistema (Flask)
5. **database.db** - arquivo de banco de dados (SQLite)

**Tabelas do Banco de Dados**

1. **usuarios**
	* id
	* nome
	* email
	* senha
	* data_nascimento
2. **produtos**
	* id
	* nome
	* conteúdo
	* preço
	* quantidade
3. **compras**
	* id
	* usuario_id
	* produto_id
	* data_compra

**Rotas da API**

1. **/register**
	* POST: criar novo usuário
2. **/login**
	* POST: autenticar usuário
3. **/compras**
	* POST: adicionar produto à carrinho
	* GET: obter produtos do carrinho
4. **/compras/confirmar**
	* POST: confirmar compra
5. **/admin**
	* POST: adicionar produto
	* GET: obter lista de produtos
