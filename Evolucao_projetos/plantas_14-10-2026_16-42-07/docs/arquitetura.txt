# Arquitetura do Site Verde VIVO

## Visão Geral

O site Verde VIVO é uma loja virtual especializada em plantas ornamentais, vasos, acessórios e produtos para jardinagem. A arquitetura do site visa criar uma experiência moderna, minimalista e responsiva, com uma paleta de cores clara e diferenciada.

## Módulos

1. **Cabeçalho**
	* Logotipo textual e ícone minimalista de folha
	* Menu de navegação com links para Início, Plantas, Vasos, Jardinagem, Acessórios e Ofertas
	* Ícones de pesquisa, conta do usuário, favoritos e carrinho de compras
2. **Página inicial**
	* Seção principal de destaque com título e subtítulo
	* Imagem ampla de plantas ornamentais em vasos de cerâmica
	* Botões para Explorar plantas e Descobrir acessórios
	* Diferenciais com ícones minimalistas
3. **Catálogo de produtos**
	* 20 produtos divididos em quatro categorias: Plantas de Interior, Suculentas, Vasos Decorativos e Jardinagem
	* Cards visuais para cada produto com imagem, título, preço, avaliações e botões de favoritar ou adicionar ao carrinho

## Arquivos

1. **static**
	* index.html (página inicial)
	* style.css (estilo do site)
	* script.js (scripts do site)
2. **backend**
	* backend.py (back-end com Flask)
3. **database**
	* database.db (banco de dados com SQLite)

## Rotas da API

1. **/api/plantas**
	* GET: listar todas as plantas
	* GET: listar uma planta por ID
	* POST: criar uma nova planta
2. **/api/vasos**
	* GET: listar todos os vasos
	* GET: listar um vaso por ID
	* POST: criar um novo vaso
3. **/api/jardinagem**
	* GET: listar todos os produtos de jardinagem
	* GET: listar um produto de jardinagem por ID
	* POST: criar um novo produto de jardinagem
4. **/api/compras**
	* GET: listar todas as compras
	* GET: listar uma compra por ID
	* POST: criar uma nova compra

## Tabelas do Banco

1. **plantas**
	* id (int)
	* nome (varchar)
	* descrição (varchar)
	* preço (float)
2. **vasos**
	* id (int)
	* tipo (varchar)
	* tamanho (varchar)
	* preço (float)
3. **produtos**
	* id (int)
	* nome (varchar)
	* descrição (varchar)
	* preço (float)
4. **compras**
	* id (int)
	* planta_id (int)
	* vaso_id (int)
	* produto_id (int)
	* quantidade (int)
	* preço (float)
