**Arquitetura do Sistema ESSENCE PARFUMS**

**Módulo 1: Estrutura da Pasta**

A pasta principal será estruturada em 3 subpasta:

*   **`/static`**: Pasta para armazenar arquivos estáticos, como imagens, estilo e scripts.
*   **`/templates`**: Pasta para armazenar arquivos de template HTML, CSS e JavaScript.
*   **`/backend`**: Pasta para armazenar o arquivo Python que contém o backend do aplicativo.

**Módulo 2: Layout da Página Inicial**

A página inicial será composta por:

*   **Título**: "SUA ESSÊNCIA. SUA IDENTIDADE."
*   **Subtítulo**: "Descubra fragrâncias exclusivas que traduzem sua personalidade e transformam cada momento em uma experiência inesquecível."
*   **Botão "Explorar fragrâncias"**: Irá levar à seção de produtos.
*   **Botão "Conhecer coleção"**: Irá direcionar ao catálogo.
*   **Imagem de destaque**: Com frascos de perfumes sofisticados sobre uma superfície escura, com iluminação dourada e composição elegante.
*   **Etiquetas visuais**: "Encontre sua assinatura olfativa" e "Elegância em cada gota".

**Módulo 3: Catálogo de Produtos**

O catálogo de produtos será composto por:

*   **Grade de produtos**: Com pelo menos 8 produtos, cada um com imagem, nome, descrição curta, categoria, volume, preço em reais e botão "Adicionar ao carrinho".
*   **Tabela de produtos**: Com os seguintes produtos:
    *   **Chanel No. 5 Eau de Parfum**: 100 ml - R$ 899,90
    *   **Dior Sauvage Eau de Toilette**: 100 ml - R$ 749,90
    *   **Carolina Herrera Good Girl**: 80 ml - R$ 699,90
    *   **Jean Paul Gaultier Le Male**: 125 ml - R$ 649,90
    *   **Lancôme La Vie Est Belle**: 75 ml - R$ 679,90
    *   **Versace Eros**: 100 ml - R$ 499,90
    *   **Calvin Klein CK One**: 100 ml - R$ 299,90
    *   **Yves Saint Laurent Libre**: 90 ml - R$ 799,90

**Módulo 4: Rotas da API**

As rotas da API serão:

*   **`/produtos`**: Irá listar todos os produtos e retornar uma lista em formato JSON.
*   **`/produtos/<id>`**: Irá retornar detalhes de um produto específico em formato JSON.
*   **`/carrinho`**: Irá atualizar o carrinho de compras com o produto selecionado.
*   **`/pedidos`**: Irá criar um novo pedido de compra.

**Módulo 5: Banco de Dados**

O banco de dados será estruturado como uma tabela `produtos` com as seguintes colunas:

| Nome | Tipo | Descrição |
| --- | --- | --- |
| id | int | Identificador do produto |
| nome | str | Nome do produto |
| imagem | str | Imagem do produto |
| descricao | str | Descrição do produto |
| categoria | str | Categoria do produto |
| volume | str | Volume do produto |
| preço | float | Preço do produto |
| quantidade | int | Quantidade do produto disponível |
| id_usuario | int | Identificador do usuário que comprou o produto |

**Módulo 6: Estrutura da Pasta Backend**

O arquivo Python que contém o backend do aplicativo será estruturado em 3 seções:

*   **Seção `app.py`**: Irá importar as rotas da API e iniciar o servidor.
*   **Seção `models.py`**: Irá importar a tabela de produtos e criar os métodos para manipular a tabela.
*   **Seção `routes.py`**: Irá importar as rotas da API e criar os métodos para lidar com as requisições.

**Módulo 7: Estrutura da Pasta Frontend**

O arquivo de template HTML será estruturado em 3 seções:

*   **Seção `index.html`**: Irá contem a página inicial.
*   **Seção `produtos.html`**: Irá contem o catálogo de produtos.
*   **Seção `carrinho.html`**: Irá contem o carrinho de compras.
