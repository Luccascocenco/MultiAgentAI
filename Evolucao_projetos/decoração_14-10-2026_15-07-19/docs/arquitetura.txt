**Arquitetura da CASA NUVEM**

**1. Visão Geral**
A CASA NUVEM é uma loja virtual especializada em decoração, organização e utilidades para casa. O site é responsivo e acessível, oferecendo uma experiência de compra tranquila e confortável.

**2. Módulos**

*   **Cabeçalho**: apresenta o logotipo textual, menu de navegação e ícones para pesquisa, conta e favoritos.
*   **Página Inicial**: apresenta a seção principal de destaque (hero section), com texto e imagem; seção de categorias com cards visuais; seção de favoritos para o seu lar; e seção de produtos no catálogo.
*   **Catálogo de Produtos**: apresenta os produtos em uma grade responsiva, com quatro colunas em telas grandes, duas em tablets e uma ou duas em celulares.

**3. Lista de Arquivos**

| Arquivo | Descrição |
| :------- | :----------- |
| `index.html` | Página inicial do site |
| `style.css` | Estilo do site |
| `script.js` | Script do site |
| `backend.py` | Back-end do site |
| `database.db` | Banco de dados do site |

**4. Tabelas do Banco**

| Coluna | Tipo de Dados | Descrição |
| :----- | :------------ | :----------- |
| id      | int           | Chave primária |
| nome    | varchar(255) | Nome do produto |
| preco   | float         | Preço do produto |
| imagem  | blob          | Imagem do produto |
| categoria | varchar(255) | Categorização do produto |

**5. Rotas da API**

| Método | Rota | Descrição |
| :----- | :--- | :---------- |
| GET    | `/produtos` | Retorna uma lista de produtos |
| GET    | `/produtos/:id` | Retorna um produto específico |
| POST   | `/produtos` | Insere um novo produto |
| PUT    | `/produtos/:id` | Atualiza um produto específico |
| DELETE | `/produtos/:id` | Exclui um produto específico |
