**API**

* `POST /users`: Cria um novo usuário
	+ Body: `username`, `email`, `password`
	+ Resposta: `user_id`
* `POST /products`: Cria um novo produto
	+ Body: `name`, `description`, `price`, `category`
	+ Resposta: `product_id`
* `GET /products`: Retorna uma lista de produtos
	+ Query Parameters: `category`, `brand`, `price`
* `GET /orders`: Retorna uma lista de pedidos
	+ Query Parameters: `user_id`, `status`
* `POST /orders`: Cria um novo pedido
	+ Body: `user_id`, `product_id`, `quantity`
	+ Resposta: `order_id`
* `POST /payments`: Realiza um pagamento
	+ Body: `order_id`, `payment_method`
	+ Resposta: `payment_id`

**Implementação da API**

* `users.js`:
```javascript
const express = require('express');
const router = express.Router();
const bcrypt = require('bcrypt');

router.post('/', (req, res) => {
  const { username, email, password } = req.body;
  const salt = bcrypt.genSalt(10);
  bcrypt.hash(password, salt, (err, hash) => {
    if (err) {
      res.status(500).send({ message: 'Erro ao criar usuário' });
    } else {
      const user = { id: 1, username, email, password: hash };
      res.send(user);
    }
  });
});

module.exports = router;
```
* `products.js`:
```javascript
const express = require('express');
```

**Logica de Autenticação**

* `users.js`:
```javascript
const express = require('express');
const router = express.Router();
const bcrypt = require('bcrypt');

router.post('/', (req, res) => {
  const { username, password } = req.body;
  const user = { id: 1, username, password: 'hashed' };
  const isValid = bcrypt.compareSync(password, user.password);
  if (isValid) {
    res.send({ message: 'Usuário autenticado com sucesso' });
  } else {
    res.status(401).send({ message: 'Usuário não autenticado' });
  }
});

module.exports = router;
```
