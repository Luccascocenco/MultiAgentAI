**Visão Geral**
--------------

Apresentamos a arquitetura de uma loja de esmaltes e itens de unhas, focada em uma abordagem simples e flexível. O sistema é dividido em módulos para facilitar o manutenimento e a escalabilidade.

**Módulos**
------------

1. **Loja de Esmaltes**: gerencia a lista de esmaltes e seus detalhes.
2. **Itens de Unhas**: gerencia a lista de itens de unhas e seus detalhes.
3. **Pedidos**: gerencia os pedidos de clientes e seus detalhes.

**Arquivos**
------------

**Front-end**

* **static/index.html**: arquivo de inicialização do sistema, contendo a estrutura básica da página.
* **static/style.css**: arquivo de estilos, definindo a aparência da página.
* **static/script.js**: arquivo de script, contendo a lógica de interação do usuário.

**Back-end**

* **backend.py**: arquivo de backend, contendo a lógica de negócios e a interação com o banco de dados.

**Banco de Dados**

* **database.db**: arquivo de banco de dados SQLite, contendo as tabelas necessárias:
	+ **pedidos**
		- id (primary key)
		- cliente
		- itens (lista de itens de pedido)
	+ **itens**
		- id (primary key)
		- nome
		- preço
	+ **esmaltes**
		- id (primary key)
		- nome
		- cor

**Rotas da API**
-----------------

* **GET /pedidos**: lista todos os pedidos.
* **GET /pedidos/:id**: lista um pedido específico.
* **POST /pedidos**: cria um novo pedido.
* **GET /itens**: lista todos os itens.
* **GET /itens/:id**: lista um item específico.
* **POST /itens**: cria um novo item.
* **GET /esmaltes**: lista todos os esmaltes.
* **GET /esmaltes/:id**: lista um esmalte específico.
* **POST /esmaltes**: cria um novo esmalte.

**Observações**
--------------

* Todas as rotas da API devem ser seguras, utilizando autenticação e autorização apropriadas.
* As rotas da API devem ser documentadas com descrições claras e exemplos de solicitação e resposta.
