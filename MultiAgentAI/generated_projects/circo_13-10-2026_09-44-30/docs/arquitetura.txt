**Visão Geral**

O site CIRCO FANTASIA é uma plataforma de marketing e vendas de ingressos para um circo itinerante, com uma identidade visual mágica, divertida e encantadora. O site é responsivo e acessível, com uma boa experiência de usuário.

**Módulos**

1. **Cabeçalho**: Contém o logotipo textual CIRCO FANTASIA, um ícone de estrela ou cartola, menu de navegação e botões de destaque.
2. **Página Inicial**: Presenta a seção principal do espetáculo, incluindo título, subtítulo, botões de ver espetáculos e comprar ingressos, imagem de destaque e pequenas etiquetas visuais.
3. **Catálogo de Espanacos e Atrações**: Contém uma grade com atrações fictícias, cada uma com imagem ilustrativa, nome, descrição e etiqueta de categoria.
4. **Ingressos**: Contém uma lista de ingressos disponíveis para cada espetáculo, com botão de compra.

**Arquivos**

1. **static/index.html**: arquivo HTML principal do site.
2. **static/style.css**: arquivo CSS que define as estilizações do site.
3. **static/script.js**: arquivo JavaScript que define as interações do site.
4. **backend.py**: arquivo Python que define a lógica do site, utilizando Flask.
5. **database.db**: arquivo SQLite que armazena a estrutura do banco de dados.
6. **config.py**: arquivo Python que define as configurações do site, incluindo URLs, credenciais e outras opções.

**Tabelas do Banco de Dados**

1. **diagramas**: contém as informações dos espetáculos e atrações.
	* diagramas.id (int, primário)
	* diagramas.nome (varchar(50))
	* diagramas.descrição (varchar(200))
	* diagramas.categoria (varchar(20))
	* diagramas.imagem (varchar(100))
2. **ingressos**: contém as informações dos ingressos.
	* ingressos.id (int, primário)
	* ingressos.diagrama_id (int, chave estrangeira)
	* ingressos.data (varchar(10))
	* ingressos.preco (float)
	* ingressos.status (varchar(10))
3. **users**: contém as informações dos usuários.
	* users.id (int, primário)
	* users.nome (varchar(50))
	* users.email (varchar(50))
	* users.senha (varchar(50))

**Rota da API**

1. **GET /diagramas**: retorna a lista de espetáculos e atrações.
2. **GET /diagramas/:id**: retorna as informações de um espetáculo específico.
3. **GET /ingressos**: retorna a lista de ingressos disponíveis.
4. **GET /ingressos/:id**: retorna as informações de um ingrediso específico.
5. **POST /ingressos**: cria um novo ingrediso.
6. **PUT /ingressos/:id**: atualiza as informações de um ingrediso específico.
7. **DELETE /ingressos/:id**: apaga um ingrediso específico.

**Rotas de URL**

1. **/**: página inicial do site.
2. **/diagramas**: página de catálogo de espetáculos e atrações.
3. **/ingressos**: página de ingressos.
4. **/comprar-ingressos/:id**: página de compra de ingressos.
