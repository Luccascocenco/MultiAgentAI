**Visão Geral**

A loja de jogos online de terror é um sistema web que permite aos usuários comprar e baixar jogos de terror. O sistema é simples e apenas serve para realizar operações básicas de compra e baixar jogos.

**Módulos**

*   Módulo de Login: gerencia as operações de login e autenticação do usuário.
*   Módulo de Jogos: gerencia a lista de jogos disponíveis para compra e baixa.
*   Módulo de Carrinho: permite aos usuários adicionar e remover jogos do carrinho de compras.
*   Módulo de Compras: gerencia as operações de compra e pagamento dos jogos.

**Lista de Arquivos**

*   static/index.html: arquivo principal do front-end que define a estrutura básica da página.
*   static/style.css: arquivo CSS que define a estilização do front-end.
*   static/script.js: arquivo JavaScript que define as interações do front-end.
*   backend.py: arquivo Python que define a lógica do back-end.

**Tabelas do Banco**

*   **usuários**: armazena informações do usuário, incluindo nome, email e senha.
    -   id (inteiro, auto-incrementável, primário)
    -   nome (varchar)
    -   email (varchar)
    -   senha (varchar)
*   **jogos**: armazena informações dos jogos disponíveis para compra e baixa.
    -   id (inteiro, auto-incrementável, primário)
    -   nome (varchar)
    -   conteudo (text)
    -   preco (real)
*   **carrinhos**: armazena as operações de compra e pagamento dos jogos.
    -   id (inteiro, auto-incrementável, primário)
    -   usuario_id (inteiro, refere-se ao id do usuário que comprou o jogo)
    -   jogo_id (inteiro, refere-se ao id do jogo comprado)
    -   quantidade (real)

**Rotas da API**

*   **login**: rota para realizar o login do usuário.
    -   URL: /login
    -   Método: POST
    -   Corpo da requisição: objeto com os campos nome e senha do usuário
*   **jogos**: rota para listar os jogos disponíveis para compra e baixa.
    -   URL: /jogos
    -   Método: GET
    -   Parâmetros: filtro por nome do jogo
*   **carrinho**: rota para adicionar e remover jogos do carrinho de compras.
    -   URL: /carrinho
    -   Método: POST/PUT
    -   Corpo da requisição: objeto com o id do jogo a adicionar ou remover do carrinho
*   **compras**: rota para realizar a compra e pagamento dos jogos.
    -   URL: /compras
    -   Método: POST
    -   Corpo da requisição: objeto com os detalhes da compra
