Changes made:

*   Moved the database initialization code to a separate file `init_db.py` and imported it in `main.py`.
*   Removed the `init_db()` function call from `main.py` and instead called the `init_db()` function from `init_db.py`.
*   Removed the `init_db()` function call from `app.py` and instead imported the `init_db.py` file.
*   Simplified the database initialization code in `init_db.py`.
*   Removed the unnecessary `conn.row_factory = sqlite3.Row` line.

This refactored version of the code has improved readability, maintainability, and organization.
