**Backend**

* Arquivo backend.py:
```python
from flask import Flask, render_template, redirect, url_for
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
app.config["SQLALCHEMY_DATABASE_URI"] = "sqlite:///database.db"
db = SQLAlchemy(app)

class Produto(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    nome = db.Column(db.String(100), nullable=False)
    descricao = db.Column(db.String(200), nullable=False)
    quantidade = db.Column(db.Integer, nullable=False)
    preco = db.Column(db.Float, nullable=False)

@app.route("/")
def index():
    return render_template("index.html")

@app.route("/produtos")
def produtos():
    produtos = Produto.query.all()
    return render_template("produtos.html", produtos=produtos)

@app.route("/adicionar-produto", methods=["POST"])
def adicionar_produto():
    nome = request.form["nome"]
    descricao = request.form["descricao"]
    quantidade = request.form["quantidade"]
    preco = request.form["preco"]
    produto = Produto(nome=nome, descricao=descricao, quantidade=quantidade, preco=preco)
    db.session.add(produto)
    db.session.commit()
    return redirect(url_for("produtos"))

if __name__ == "__main__":
    app.run(debug=True)
```

button.addEventListener("click", function() {
    // Adicionar produto ao carrinho
    const produtoId = button.dataset.produtoId;
    // Consultar banco de dados
    const produto = Produto.query.get(produtoId);
    // Criar pedido
    const pedido = {
        produtoId: produtoId,
        quantidade: 1
    };
    // Salvar pedido no banco de dados
    db.session.add(pedido);
    db.session.commit();
    // Redirecionar para página de carrinho
    window.location.href = "/carrinho";
});

**Arquivo database.db**
```sql
CREATE TABLE produtos (
    id INTEGER PRIMARY KEY,
    nome TEXT NOT NULL,
    descricao TEXT NOT NULL,
    quantidade INTEGER NOT NULL,
    preco REAL NOT NULL
);
```
**Rotas da API**

* GET /produtos: retornar todos os produtos
* POST /adicionar-produto: adicionar novo produto ao banco de dados
* GET /carrinho: retornar pedido atual
* POST /carrinho: atualizar pedido
* GET /pedidos: retornar todos os pedidos

**Banco de dados**

* Tabela produtos:
	+ id (int, primário)
	+ nome (varchar, 100, não nulo)
	+ descricao (varchar, 200, não nulo)
	+ quantidade (int, não nulo)
	+ preco (real, não nulo)
* Tabela pedidos:
	+ id (int, primário)
	+ produtoId (int, não nulo)
	+ quantidade (int, não nulo)
