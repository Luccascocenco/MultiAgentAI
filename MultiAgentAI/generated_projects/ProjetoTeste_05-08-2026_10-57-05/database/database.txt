**Banco de Dados**

O banco de dados do sistema será composto pelas seguintes tabelas:

```sql
CREATE TABLE usuarios (
  id_user INT PRIMARY KEY AUTO_INCREMENT,
  nome VARCHAR(255) NOT NULL,
  email VARCHAR(255) NOT NULL UNIQUE,
  senha VARCHAR(255) NOT NULL
);

CREATE TABLE exercicios (
  id_exercicio INT PRIMARY KEY AUTO_INCREMENT,
  nome_exercicio VARCHAR(255) NOT NULL,
  tipo_exercicio ENUM('com equipamento', 'sem equipamento') NOT NULL,
  tempo_duração INT NOT NULL,
  dificuldade ENUM('fácil', 'medio', 'dificil') NOT NULL,
  numero_repeticoes INT NOT NULL
);

CREATE TABLE logotransacoes (
  id_logotran INT PRIMARY KEY AUTO_INCREMENT,
  id_user INT NOT NULL,
  id_exercicio INT NOT NULL,
  data_transacao DATE NOT NULL,
  hora_transacao TIME NOT NULL,
  FOREIGN KEY (id_user) REFERENCES usuarios(id_user),
  FOREIGN KEY (id_exercicio) REFERENCES exercicios(id_exercicio)
);
```

**Observações:**

*   A tabela `usuarios` armazena informações sobre os usuários, incluindo o nome, e-mail e senha.
*   A tabela `exercicios` armazena informações sobre os exercícios, incluindo o nome do exercício, tipo de exercício, tempo de duração, dificuldade e número de repetições.
*   A tabela `logotransacoes` armazena registros das transações realizadas pelos usuários, incluindo a data e hora da transação, bem como as informações sobre o usuário e o exercício envolvido.
