**Arquitetura da API**

A API foi implementada utilizando Flask, uma biblioteca popular para criar APIs em Python. A API foi dividida em várias rotas, cada uma responsável por uma funcionalidade específica.

**Banco de Dados**

O banco de dados foi implementado utilizando SQLite, uma biblioteca de banco de dados in-memory que armazena os dados em uma file. A API utiliza o banco de dados para armazenar e recuperar os dados dos clientes, produtos e ordens.

**Rotas da API**

A API foi dividida em várias rotas, cada uma responsável por uma funcionalidade específica:

*   **/api/produtos**: Lista todos os produtos.
*   **/api/produtos/<int:item_id>**: Obtem um produto específico.
*   **/api/produtos**: Cria um novo produto.
*   **/api/ordens**: Cria uma nova ordem.
*   **/api/clientes**: Lista todos os clientes.
*   **/api/clientes/<int:item_id>**: Obtem um cliente específico.

**Funcionalidades**

A API foi implementada para realizar as seguintes funcionalidades:

*   Listar todos os produtos.
*   Obter um produto específico.
*   Criar um novo produto.
*   Criar uma nova ordem.
*   Listar todos os clientes.
*   Obter um cliente específico.

**Exemplos de Rotas**

Aqui estão alguns exemplos de rotas da API:

*   **GET /api/produtos**: Lista todos os produtos.
*   **GET /api/produtos/1**: Obtem um produto específico com ID 1.
*   **POST /api/produtos**: Cria um novo produto.
*   **POST /api/ordens**: Cria uma nova ordem.
*   **GET /api/clientes**: Lista todos os clientes.
*   **GET /api/clientes/1**: Obtem um cliente específico com ID 1.

**Exemplos de Comando SQL**

Aqui estão alguns exemplos de comandos SQL utilizados na API:

*   **INSERT INTO clientes (nome, email) VALUES ('João', 'joao@example.com')**: Insere um novo cliente.
*   **INSERT INTO produtos (nome, descricao, preco, imagem) VALUES ('Camiseta Oversized Preta', 'Camiseta confortável, com modelagem ampla e estilo urbano.', 79.90, 'img/camiseta_oversized_preta.jpg')**: Insere um novo produto.
*   **INSERT INTO ordens (cliente_id, produtos, preco_total) VALUES (1, 'Camiseta Oversized Preta', 79.90)**: Insere uma nova ordem.
*   **SELECT * FROM clientes**: Recupera todos os clientes.
*   **SELECT * FROM produtos**: Recupera todos os produtos.
*   **SELECT * FROM ordens**: Recupera todas as ordens.
